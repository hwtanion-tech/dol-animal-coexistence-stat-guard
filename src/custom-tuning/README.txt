动物转化共存与属性保护 0.2.0 — 实验版

0.2.0 更新：新增八种动物各自独立的转化点数防自然衰减开关。
设置入口仍在游戏侧栏“转化与属性设置”，无需控制台。
开启保护不影响正常点数增长、阶段推进；关闭后，即使开启共存，
也会按原版/框架既有条件在通常的每日结算中自然减少点数。
保留项圈、特定怀孕等原有不衰减条件；不拦截主动扣点或清除转化。

升级前备份存档，禁用旧版 0.1.0/0.1.1，导入并启用 0.2.0，完整重新加载游戏。
原有外观选择、属性保护保留。新增开关首次迁移跟随旧版行为：
旧存档共存开启则八项保护默认开启；共存关闭则八项默认关闭。
迁移后八项开关独立保存，不再随着共存开关自动变化。
新存档默认共存开启、八项点数保护开启；不要同时启用两个 MOD 版本。

重要：尚未在真实游戏里完成回归测试，不是全兼容正式版。先导出存档备份，
用副本测试。不替换或修复天使保护 MOD 已有的 17 项补丁失败。

严格适配：DoL 0.5.12.13、maplebirch 5.6.2、枯木逢春 2.5.8，
ModLoader >=2.101.1、TweeReplacer >=1.7.0、ReplacePatcher >=1.3.0。
应放在枯木逢春、默示录、天使保护及其他现有功能 MOD 后面加载。

安装：禁用只读诊断 MOD，导入此 ZIP（不要解压），启用后重新载入游戏。

功能：
1. 狼、猫、牛、鹰身、狐、鲸、马、渡鸦共存。
   使用框架共存接口，同时更新转化并取消转化之间的进度抵消。
   0.2.0 起，自然进度衰减由各动物的点数保护开关单独控制。
   主动清除、显式负向 transform、剧情处理仍可减少转化。
2. 外观仅可选择当前等级 >0 的动物转化，或“不显示”。
   初始默认不显示动物外观，必须自己选择；失去所选转化会回退为不显示。
   不改写真实转化等级或能力部位，以免隐藏外观导致能力丢失。
3. 过滤标准可见部位查询 checkTFparts，并针对 13 个外观反应段落补丁。
   含称呼、部分通用对话、悉尼互动、惠特尼抚摸、街头拍照、格威岚外观识别等。
   未全量改写全部直接读取转化等级的剧情；范围见 patch-validation.json。
   原版 main/combatMainPc 渲染参数已适配，特殊立绘、混合部件及 MOD 内
   直接读取真实变量的非标准显示尚需实测。暂不能保证所有 NPC 都仅按外观反应。
4. 各自可选防自然衰减：纯洁、容貌、体能、意志力、意识、淫乱、暴露癖、异种癖、理智。
   全部属性保护默认关闭，正常增长不受影响。
   已适配：每日意志力与体能下降、创伤造成的每日容貌下降、每日净纯洁下降、
   伤疤造成的每日纯洁下降、非硬核不适设置导致的每日三类倾向下降。
   理智：仅适配已核实的亡灵诅咒持续消耗，保留其其他效果与普通事件的理智扣除。
   意识：该版本未发现明确自然下降入口，开关仅预留，不会伪造“已保护”。
    其他来源的事件扣除、主动消费以及尚未适配的 MOD 自定义下降仍然有效。
5. 在设置窗口的“动物转化点数保护”一组，分别控制狼、猫、牛、鹰身、狐、鲸、马、渡鸦。
   关闭保护不等于立刻扣点，需要等到通常的自然衰减结算且原有条件满足。
   掉点可能使转化阶段降低、部位和能力失去；失去当前选择的转化会回退为不显示。
   不包括天使、恶魔、堕天使、亡灵，也不改变动物之间的互斥抵消规则：
   共存开启时不互相抵消；共存关闭时仍跟随原版/其他 MOD 的互斥规则。
   点数保护只保护自然衰减，不会挡住互斥抵消、剧情主动扣除或清除。

设置：复用 SugarCube 原生“设置”菜单，不改游戏主题或新增自定义布局。
进入存档后，点击侧栏的“转化与属性设置”，在窗口中找“动物共存与属性保护（实验版）”。
配置保存在当前存档的 DOLmodTuning 字段，不会给你添加未获得的动物转化。
如果 Lyra 隐藏了原生设置入口，可以在 Edge F12 控制台执行：
  SugarCube.UI.settings()
若不支持上述入口，也可直接使用以下接口（修改后正常保存游戏）：
  DOLmodTuning.owned()                     查看已拥有动物的英文 ID
  DOLmodTuning.select('cat')               选择已拥有的猫外观
  DOLmodTuning.select(null)                不显示动物外观
  DOLmodTuning.protect('willpower', true)  开启意志力防自然衰减
  DOLmodTuning.protect('willpower', false) 关闭意志力防自然衰减
  DOLmodTuning.protectTransformation('cat', true)  开启猫转化点数防自然衰减
  DOLmodTuning.protectTransformation('cat', false) 允许猫转化点数自然衰减
  DOLmodTuning.setCoexist(false)           关闭共存/外观过滤
  DOLmodTuning.status()                    查看安装状态与限制
属性英文 ID：purity、beauty、physique、willpower、awareness、promiscuity、
exhibitionism、deviancy、sanity。

切换外观后正常切换场景，使立绘与场景文本重新生成；不会追溯修改已显示的对话。

卸载：禁用并重新加载，代码补丁消失，但已保存的多个转化与数值不会自动还原。
恢复原先体验请使用安装前存档。不要用原版未支持共存的环境覆盖原始备份。

验证：对用户导出源码进行精确文本匹配及修改后 JS 语法检查，
并用模拟环境测试增长/衰减、能力数据不被外观修改、动态选择列表、
理智自然消耗与普通事件扣除的隔离；并复用实际框架算法验证共存开/关两种模式
中每次只扣一次自然点数，保留原有不衰减条件、增长及主动负向变更。
用户已反馈此前版本的外观及意志力保护等功能正常，但 0.2.0 新增点数控制尚未实测。
