# DoL Animal Coexistence & Stat Guard

DoL 动物转化共存、外观选择与属性自然衰减保护。当前版本 **0.2.0（实验版）**。

## 功能

- 狼、猫、牛、鹰身、狐、鲸、马、渡鸦共存。
- 外观只选择当前拥有的动物转化，或不显示；隐藏外观不清除真实能力数据。
- 侧栏“转化与属性设置”打开设置窗口。
- 九项属性独立防自然衰减开关。
- 八种动物转化点数独立防自然衰减开关，不阻止正常增长或剧情主动扣点。

## 环境

严格适配 DoL 0.5.12.13、maplebirch 5.6.2、枯木逢春 2.5.8。
需要 ModLoader >=2.101.1、TweeReplacer >=1.7.0、ReplacePatcher >=1.3.0。

## 安装

1. 备份存档，从 Releases 下载 `.mod.zip`，不要解压。
2. 禁用此 MOD 的旧版本及只读诊断包，仅启用一个功能版本。
3. 放在其他现有功能 MOD 后加载，完整重新启动游戏。
4. 进入存档，点击侧栏“转化与属性设置”。

外观与属性开关随当前存档保存。0.2.0 升级保留既有配置；此前启用共存的存档，新增动物点数保护默认全开。掉点可能使阶段、部位和能力降低。

## 已知限制

- NPC 外观反应只覆盖部分已适配对话，并非全量覆盖。
- 特殊立绘、混合部件和其他 MOD 的自定义逻辑仍需实测。
- 意识没有已确认的自然下降入口，开关仅预留。
- 理智仅保护已核实的亡灵持续消耗，不保护普通事件扣除。
- 不修改天使、恶魔、堕天使和亡灵的转化点数。
- 已有版本的外观及意志力保护收到用户正常反馈；新增点数控制通过自动化测试，尚待实际游戏验证。

详细说明见 `src/custom-tuning/README.txt`。

## 开发与测试

依赖 Python 3 和 Node.js。无需安装第三方依赖。

```sh
node --test tests/*.test.cjs
python tools/build_tuning.py
```

构建工具需要在本地放置对应版本的 ModLoader 合并导出包：
`MOD/Degrees-of Lewdity_ExportData_20261110_211457.zip`。
它不包含在仓库中，也不应提交。若换用不同文件名，需调整构建脚本中的 `EXPORT`。
构建将精确验证补丁目标，生成 `dist/` 安装包及本地 `work/validation/`。

部分源码集成测试依赖本地 `work/reference/inject_early.js`，缺失时自动跳过。
补丁源码测试依赖先执行构建；缺失时自动跳过。测试通过不等于所有游戏场景均已兼容。

仓库不包含游戏本体、第三方 MOD、诊断报告或存档。安装包中的匹配字符串用于版本特定补丁。
本项目与游戏及第三方 MOD 作者无隶属关系。
